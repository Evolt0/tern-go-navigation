# Changelog

## Unreleased

- 新增可选的 `jvm-navigation-host.luau`：与 Java / Kotlin 插件同时安装时使用单一原生前端，共用 Ctrl+Alt+G / S / B 和窗口跳转历史，消除两个插件重复绑定同键的冲突；Go 后端与 gopls 会话逻辑不变。
- 发布归档包含共享前端宿主模块；未安装 Java / Kotlin 插件时仍使用原 Go 界面。全局键位配置不被改写。

## 1.3.3 — 2026-10-31

- macOS 文件监听改为原生 FSEvents，通过 purego 保持 Go 1.23 和 `CGO_ENABLED=0` 构建；不再使用逐文件持有句柄、关闭后泄漏的 kqueue 路径。标准库与模块缓存合并原生监听根，保留依赖包和外部本地模块的变更覆盖。
- 查询前使用同一事件流中的唯一日志标记、原生 flush 和串行回调屏障同步磁盘事件；监听根重新配置按事件 ID 回放，保留即时修改、目录移入 / 删除与原子保存语义。事件丢失或监听根失效明确使会话失败，不吞掉监听注册错误。
- 新增真实描述符占用、成功关闭 / 取消初始化 / gopls 启动失败回收、依赖根合并及事件范围回归；发布包许可证校验改为读取实际二进制的依赖构建信息，适配不同平台后端。
- 修复双击 / 选中函数名后出现 `textDocument/references: no identifier found`：窗口发送原生选区的零基 UTF-8 字节范围，后端按当前缓冲区的选区起点转换为 LSP UTF-16 位置，支持正选、反选、Unicode 与未保存修改；选区变化也会阻止过期结果跳转，不吞掉语言服务错误。

## 1.3.2 — 2026-10-30

- 移除 `diagnosticsDelay: 1h` 人工长延迟，恢复 gopls 默认诊断调度；避免会话关闭时等待延迟任务持有的快照，导致连接断开后 daemon 仍无法按空闲超时退出。
- 正常关闭按 LSP `shutdown` / `exit` 顺序释放当前会话，超时才强制结束自己的转发客户端，保留其他共享客户端的服务。
- 共享回归测试直接持有独立 daemon 及其进程组，失败路径也会回收测试进程；新增最后一个客户端关闭后 daemon 必须实际退出的验证。
- 真实 CLI 验证未保存导航、关闭客户端后 daemon 与 telemetry 一同退出；从 `v1.3.1` 升级时，需重启旧共享服务一次，清掉已经排队的一小时延迟任务。

## 1.3.1 — 2026-10-30

- 后端改用 gopls 原生 `-remote=auto` 模式：没有服务时自动启动，与采用相同模式的 OMP 客户端共用 daemon，未保存缓冲区和工作区视图各自隔离。
- 插件只回收自己的转发客户端，不终止其他客户端正在使用的共享服务；最后一个客户端断开后按 gopls 的默认空闲超时退出。
- 增加真实 gopls 回归，验证两个客户端连接同一 daemon、未保存定义行号互不覆盖，以及关闭一个客户端后另一个继续查询；中英文说明补充 OMP 配置、已有会话重载和进程数量的解释。

## 1.3.0 — 2026-10-30

- 新增 `Go: Search project symbols`（`Ctrl+Option+S`）：按名称搜索当前项目的函数、方法、类型和变量，包含未打开文件及未保存修改，保留代码预览与跳转返回。
- 搜索使用 gopls 的 workspace 范围并再次按真实项目路径过滤，排除标准库、外部依赖、vendor、未加入的嵌套模块及符号链接逃逸；支持 `go.work` 的外部成员模块。
- 聚焦 Go 文件后尝试后台预热；编辑器进程存活期间不再因空闲 5 分钟退出 gopls。无窗口上下文的 CLI 仍有空闲回收；编辑器退出或后端被替换后回收服务。
- 快速查询不再立即弹出“正在查询”通知；仅耗时超过 600 ms 时显示提示。无效查询参数不再丢弃已加载会话。
- 接受 gopls 合法的工作区相对监听模式；保留外部依赖目录发现，不以减少监听覆盖换取启动时间。
- 实测自动预热后的桌面首次导航约 34.8 ms，项目函数搜索约 54.4 ms；后台加载成本仍存在，完整测量和边界见 README。
- README 增加项目查询截图、缓存生命周期说明及 VS Code / Zed / gopls 参考；克隆地址改为 `git@github.com:Evolt0/tern-go-navigation.git`。
- `go test -race ./...` 通过；真实桌面验证自动预热、未打开文件查询、未保存改名、返回和标准库排除，并确认同一 gopls 进程复用。另验证编辑器退出和二进制替换会自动回收旧服务。
- README 主页改为英文，新增完整中文 README 和语言切换；统一使用新仓库名与 Git SSH 克隆地址。
- 新增版本标签触发的 GitHub Releases 工作流：版本校验、竞态测试、macOS / Linux 的 arm64 / amd64 原生打包、SHA-256 校验及真实 gopls 发布包 CLI 冒烟检查；手动运行默认仅生成构建产物，指定已有 `release_tag` 可补充缺失平台附件，不改写已发布标签或覆盖已有附件。
- 发布包包含可执行后端、中英文文档、截图、变更记录与实际编译依赖的许可证；Go 和 gopls 仍为运行时要求。

## 1.2.1 — 2026-10-29

- 导航列表增加命中行源码预览，放在完整路径之前，保留文件名、行列和定义 / 引用分组。
- 预览优先取未保存缓冲区；复用查询中的源文本，无额外 gopls 请求或文件读取，并覆盖 CRLF、Tab 和 Unicode 内容。
- 当前原生选择器仅支持行内说明，不支持独立的选中项预览区域。
- 修复 kqueue 同步标记的创建 / 删除竞争，改为预先监听常驻标记文件后单次写入，避免快速查询等待不到删除事件而超时。
- 模块发现使用 `go list -m -e -json all`，依赖解析不完整时仍监听可用的工作区外模块，避免磁盘修改后返回旧行号；集成测试禁用网络依赖。
- `go test -race ./...` 通过，原失败的并发启动、外部工作区及原子保存用例连续三轮通过；真实桌面验证未保存源码预览和选择后跳转，实际 CLI 验证外部文件修改立即更新预览行号。
- README 增加真实导航列表和定义跳转截图，重组功能介绍，并补全源码安装、更新、卸载、工具链查找及平台限制说明。

## 1.2.0 — 2026-10-29

- 合并定义与调用 / 引用查询为 `Go: Navigate symbol`（`Ctrl+Option+G`），同一选择器分组展示；旧的 definition / references 命令及独立引用快捷键移除，自定义绑定改用 `plugin.go-navigation.navigate`。
- gopls 改为按窗口、工作区常驻复用，避免每次查询重新初始化索引；缓冲区按变更同步，读取多个编辑器快照时并发执行。
- 常驻服务使用本机私有 Unix socket，空闲 5 分钟退出；不同窗口的 overlays 隔离，后端升级使用新服务。
- 文件监听使常驻索引随磁盘源文件、外部本地模块及 go.mod / go.work 变化更新；查询中断会释放受影响会话，后续请求重建。
- `go test -race ./...` 通过；真实桌面验证合并选择器、定义 / 调用跳转、返回、未保存缓冲区与过期结果保护。
- 三文件 `net/http` 示例的合并热查询中位数从旧版 523.5 ms 降至 6.2 ms；首次查询仍需索引，实测 613–1140 ms。
- 实测 Tern 0.9.7 普通符号 Command+点击不会触发插件路由，URL 点击会触发。该交互需要 Tern 宿主开放原生编辑器点击接口，本插件未声称支持。

- 引用选择器优先显示文件名及行列，避免长路径遮住文件名；返回时不再重复聚焦当前面板。
- 在缺少 Go 的 GUI PATH 下完成真实桌面定义 / 引用快捷键验证，包括多结果选择与返回原行列。
